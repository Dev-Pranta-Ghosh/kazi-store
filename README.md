# Kazi Store — Premium Cosmetics eCommerce Website

A modern and premium cosmetics eCommerce website designed and developed for **Kazi Store — কাজী স্টোর**, a cosmetics retailer based in Chattogram, Bangladesh.

The website delivers a sophisticated online shopping experience with product discovery, advanced filtering, search, wishlist, shopping cart, checkout, customer account interfaces, and a fully responsive design.
